# Product Roadmap & Strategic Vision: Alert Lens NG

> **Distinction Note**: Items listed under Phase 1 describe the **Existing Current Prototype Capabilities**. Items listed under Phase 2 and Phase 3 represent the **Future Product Vision**.

---

## 🚀 Phase 1: Production-Ready Web Prototype (CURRENT PROTOTYPE)

* **Multi-Channel Content Checker**: Complete support for evaluating messages, URLs, email text, job listings, and social media offers.
* **Scam Procedure Detection Engine**: Automated detection and risk-rating of requested sensitive actions (`LOGIN`, `PROVIDE_OTP`, `PROVIDE_BVN`, `PAY_FEE`).
* **URL Intelligence & TLD Classifier**: Detection of suspicious top-level domains, IP hosts, link shorteners, and lookalike domains.
* **Controlled Navigation System**: `ProtectedLink` and `ProtectionInterstitialModal` ensuring users pause before entering risky external URLs.
* **Context-Aware Independent Verification**: Tailored verification steps for Banking, Educational, Corporate, and E-Commerce institutions enforcing the Golden Safety Rule.
* **Interactive Safety Center & Tutorials**: 8 scenario-based learning modules covering top digital fraud vectors.
* **Scannable History & Mobile Quick View**: History grouping by channel with a responsive Quick View modal for mobile screens.
* **Alert AI Conversational Layer**: Grounded Q&A assistant providing context-aware answers to user follow-up questions.

---

## 🔮 Phase 2: Browser Extension & Active Web Interception (FUTURE VISION)

* **Chrome & Firefox Extension**: Extension overlay that scans incoming links directly inside WhatsApp Web, Gmail, Outlook, and webmail clients before the user clicks.
* **On-Page Link Highlighting**: Automatically decorates links inside web pages with `ALLOW` (Green), `WARN` (Yellow), and `BLOCK` (Red) indicators.
* **Encrypted Cross-Device Sync**: Optional end-to-end encrypted sync of user check history across browser instances without requiring centralized server account storage.
* **Offline On-Device AI Models**: Integration with lightweight WebLLM / Chrome Built-in AI (`window.ai`) for 100% offline local inference.

---

## 🌐 Phase 3: Ecosystem & Institutional Integration (FUTURE VISION)

* **Mobile Security SDK & SMS Overlay**: Native Android / iOS SDK providing real-time floating overlay alerts when suspicious SMS or WhatsApp messages are received.
* **Financial & Teleco Threat API Gateway**: Enterprise API enabling banks, telecom providers, and e-commerce platforms to query reported scam procedures and block fraudulent shortcodes.
* **Community-Sourced Threat Feeds**: Decentralized reporting mechanism allowing users to submit confirmed new scam templates and domain variants to update protection rules in real time.
* **Multi-Language Regional AI Fine-Tuning**: Specialized fine-tuning for regional languages and slang across West Africa (Yoruba, Hausa, Igbo, Pidgin English).
